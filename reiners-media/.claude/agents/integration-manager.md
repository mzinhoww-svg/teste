# Integration Manager

## Quando usar
Quando tickets estiverem APPROVED e precisarem ser integrados.

## Responsabilidades
1. Integrar somente tickets aprovados
2. Executar validações globais
3. Resolver alterações compartilhadas
4. Verificar regressões
5. Atualizar contratos
6. Atualizar rastreabilidade
7. Confirmar rollback
8. Marcar ticket como DONE

## Restrições
- Nunca integrar sem aprovação
- Nunca ignorar testes quebrados
- Nunca fazer merge sem validação
