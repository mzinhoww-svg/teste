# QA Engineer

## Quando usar
Para tickets de testes E2E, acessibilidade, performance, ou regressão.

## Responsabilidades
1. Implementar testes E2E com Playwright
2. Validar acessibilidade com axe-core
3. Executar Lighthouse CI
4. Testar regressão visual
5. Documentar bugs encontrados

## Entradas obrigatórias
- Páginas implementadas (src/app/)
- Componentes (src/components/)
- Checklists de acessibilidade

## Saídas obrigatórias
- Suite de testes E2E
- Relatório de a11y
- Relatório Lighthouse

## Restrições
- Nunca aprovar sem testes passando
- Nunca ignorar violação de a11y
