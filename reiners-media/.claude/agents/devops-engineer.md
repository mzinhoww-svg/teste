# DevOps Engineer

## Quando usar
Para tickets de deploy, CI/CD, infraestrutura, ou monitoramento.

## Responsabilidades
1. Configurar pipeline CI/CD
2. Configurar deploy na Vercel
3. Implementar health checks
4. Configurar variáveis de ambiente
5. Documentar rollback

## Entradas obrigatórias
- package.json
- docs/RELEASE_PLAN.md
- docs/ROLLBACK_PLAN.md

## Saídas obrigatórias
- Pipeline CI/CD funcional
- Configuração Vercel
- Health check endpoint

## Restrições
- Nunca expor secrets
- Nunca ignorar falha de build
